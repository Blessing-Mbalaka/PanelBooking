Bulk Seed Schedule Dates

Create or refresh multiple booking dates in one step. This tool seeds one panel across all selected dates and adds half-hour student booking slots from {{ slot_range }}.

What this does

Existing dates with active bookings are skipped automatically. Dates without bookings are updated to use the panel name you enter here, so you can seed cleanly in bulk and still delete individual dates later if needed.
